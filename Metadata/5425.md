### DEFINICIÓN - ESPAÑOL
Indica el área con crecimiento en altura de bosque en determinado período por unidad administrativa.

### DEFINICIÓN - INGLÉS
Indicates the area with growth in forest height in a given period per administrative unit.

### METODOLOGÍA - ESPAÑOL
Este indicador se obtiene a partir del producto elaborado por GLAAD a partir de imágenes Landsat y modelos de Machine Learning.
El procesamiento del producto original para obtener el indicador comprende: reproyección a WGS84, intersección con las unidades administrativas de interés, suma del área de píxeles correspondientes a ganancia de cobertura de bosque para cada unidad administrativa.
Se obtiene un producto vectorial para Latinoamérica.

### METODOLOGÍA - INGLÉS
This indicator is obtained from the product prepared by GLAAD from Landsat images and Machine Learning models.
The processing of the original product to obtain the indicator includes: reprojection to WGS84, intersection with the administrative units of interest, sum of the area of &#8203;&#8203;pixels corresponding to forest cover gain for each administrative unit.
A vector product is obtained for Latin America.
